# Audit remediation

The follow-up audit found real defects. This revision corrects the following, with regression coverage in `tests/test_regressions.py` and the existing suite:

| Failure | Correction |
|---|---|
| Late historical events falsely permit first-time goals | Recheck all currently known effective-before-start evidence; invalidate open and closed goals. |
| Older billing receipt reactivates a lapsed subscriber | Order billing by effective time, compare snapshot versions, fail closed on ties. |
| SQLite reader exception aborts a decision | Record a complete abstention; independent fsynced failure journal when SQLite cannot write. |
| Blocking custom provider exceeds deadline | Killable process with bounded wait and deterministic fallback. |
| Premature PUBLISHED state and unsafe restart | PENDING outbox, transactional dispatch, published-only export, cancel pending on restart. |
| Competing active plan deletes history | Plan-ID upsert respects the independent one-open-plan constraint. |
| Stale viewer and contradictory plan/result state | Synchronize active-plan projection and reconcile final plan status with judgment. |
| G08 window drifts on continuation | Anchor content selection to original goal commitment. |
| Incomplete budget/failure decisions | Validate shared required schema, explicit evidence and abstention reason. |
| Wrong provenance freshness | Signup uses receipt observation; paid references retain their individual timestamps; rule correction uses its own timestamp. |
| Wrong-language titles | Require both language and dialect in selection and independent verification. |
| Fixed confidence and unused failure history | Confidence exposes evidence components; failed-goal cooldown affects subsequent selection. |
| Pointless model calls | Skip stale and non-actionable triggers except named fault fixtures. |

## Executed validation

- 43 tests passed, including 16 audit regressions. Existing targeted G03 correction test changes an actual open plan, preserves its deadline, rejects next-day app-open success, and accepts next-day play. The ordinary supplied replay has no open matching goal at correction time; it alone does not demonstrate that migration.
- Final supplied replay: 2,679 decisions, 541 published pages, 910 judgments; all five model faults reproduced; zero simulator policy violations. The independent artifact validator checks randomized arms, session deduplication, language/dialect, availability, deadlines, evidence timing and success signals.
- Isolated 3× busiest evening window: 165 deliveries expanded to 495; 3,005 unique decisions and 609 pages overall; zero policy violations and no decisions above 60 seconds. Aggregate p95 approximately 9.69 ms, maximum 2,004.13 ms with explicitly modeled dependency waits. This is an accelerated single-worker replay, not production concurrency proof. See `validation/` for measured reports and fixture manifest.
- Original pack and simulator unchanged. Sample exports include every viewer snapshot and simulator event; SQLite is regenerated by running the CLI.

## Interpretation and remaining scope

Primary randomized completion difference is +1.75 percentage points (95% CI −2.98 to +6.45), which does not establish benefit. The project demonstrates the complete local decide/act/measure loop for home pages; it does not claim production deployment or every possible channel. Messaging and G06/G07/G10/G11 remain explicitly excluded as described in README and KNOWN_LIMITATIONS. Per-decision dispatch timing precedes final bookkeeping; aggregate latency includes bookkeeping. Recovery cancels uncertain pending work; there is no remote delivery acknowledgment or crash-resumable replay CLI. No new independent audit score is claimed.
