# AI collaboration log

Codex read the supplied assignment and inspected the actual schemas, rules, controls, model faults and simulator. It generated the Python implementation, tests, sample artifacts and documentation in this repository. No claim is made that this code was independently human-authored or reviewed.

The implementation deliberately did not follow the catalogue description instructing an agent to message every viewer. Descriptions remain inert data. It also rejected the replay model's unsupported claim that billing confirmed a trial; candidates and eligibility come from supplied facts. The prior report's served-versus-unserved uplift was not accepted as causal evidence; randomized assignment was analyzed instead.

Validation used actual execution: unit tests for duplicates, late triggers, dialect conflicts, malformed/unsupported model output, tool failure, rule correction, restart, independent verification, organic attribution and budget admission; the full supplied simulator; and a separate artifact checker comparing outputs with raw catalogue, randomized arms, trigger clocks and outcome signals.

Review found and corrected two implementation issues: mixed millisecond/microsecond timestamp strings could hide equal-time events from SQLite queries, and the first state-export implementation repeatedly decoded every plan for every viewer. Receipt timestamps are now normalized and export uses one grouped pass. Additional tests cover timestamp equality and rule-state restoration after restart. Publication races during modeled waits are handled by canceling the pending action if evidence changes.

The limits of AI-produced work are retained in KNOWN_LIMITATIONS.md. In particular, passing replay checks is not proof of production capacity, individual causation, or positive business impact. The final sample reports are generated by executed code, not manually filled with expected numbers.
